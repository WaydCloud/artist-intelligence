## 1. 서사가 이름을 못 부르던 것 (닫힘)

두 관문을 통과한 팀이 누구인지가 **인사이트 문자열에만** 있었다. 랜딩은 규율상 문장을 파싱하지 않으므로 자기 결론의 주인공을 못 불렀다.

- signal-bridge가 `gate-passed` 막대로 **이름**을 싣는다. 수(`판정 가능 선행`)는 지표가 이미 들고 있었으므로 더한 것은 이름뿐이다.
- 🔑 **판정을 `_gate_passed()` 한 곳으로 모았다.** 같은 조건이 지표·교차표 문장·차트 셋에 따로 적혀 있으면 한쪽만 고쳐질 때 화면의 세 자리가 다른 팀을 말한다.
- **스키마는 안 건드렸다.** `barData`가 닫혀 있어 막대에 필드를 더하는 것은 별도 승인 사안이다. `{name, value}` 두 칸으로 충분했다.
- 통과 0팀이면 차트를 만들지 않고 서사는 수로만 닫는다. **있는데 어긋나면**(이름 > 통과 수) `lib/story.ts`가 빌드를 세운다.
- 규율은 `DESIGN.md` §7.8에 등재: *수만이 아니라 이름도 구조로 온다.*

## 2. genre-impulse 노브 라벨의 표기 누출 (닫힘)

`하위 백분위 P_low`·`상위 백분위 P_high`가 기준 원장 화면의 슬라이더 라벨로 그대로 떴다.

- 모듈이 `하한으로 볼 백분위`·`상한으로 볼 백분위`로 싣는다. 대시보드 폴백 4곳과 빈 상태 문구(`P_low를 올리거나…`)도 같이 고쳤다.
- 원장 표에 **화면 표기 열**을 더해 기호와 표기를 나란히 뒀다 — 화면에서만 고치면 원장과 갈라진다.
- 규율은 `DESIGN.md` §7.5: **문서에서만 통하는 기호도 저장 키와 같다.**

## 3. 🔴 육안 결함 하나 (서른한째 건)

**통과가 1팀이라 새 막대가 폭 100%로 그려졌다.** 게이지가 가득 찬 것처럼 읽히는데 실제로 비교한 대상은 자기 자신이다 — 막대 길이는 언제나 *보이는 것 중 최댓값* 기준이기 때문이다.

- `BarChart`가 **행이 하나면 길이를 그리지 않는다.** 값을 지우는 것이 아니라 **없는 비교를 지운다.** 이름과 값은 이미 텍스트라 잃는 정보가 0이다.
- 딸린 것: 차트 `definition`도 행이 하나일 때 참이어야 한다("막대 길이는 …"이라고 적으면 그날 화면에 없는 것을 가리킨다).
- 정적 게이트 5종과 `smoke:tabs` 12건을 **전부 통과한 상태**였다. 여덟 라운드째 같은 패턴이다.

## 4. 🔴 오늘 09:00 수집이 깨져 있었다 — 네 겹 (D-054 ⑥)

로그에 `!! social merge FAILED`가 있는데 하루가 `done`으로 닫혀 있었다. **산 $3어치가 리포트에 못 들어간 채 재시도도 돌지 않았다.** 넷 다 어제 D-054 변경에서 왔고, **유료 경로가 처음 실제로 도는 날 한꺼번에 터졌다.**

| # | 무엇 | 왜 |
|---|---|---|
| 1 | 시도 원장이 **스냅샷 디렉터리 안**에 있었다 | `data/live/social/`은 `merge_social.py`가 `*.json`으로 훑는 자리다. 원장이 스냅샷인 척 끼어들었다 |
| 2 | PS 5.1 `Set-Content -Encoding utf8`이 **BOM**을 붙인다 | 파이썬 `json.loads`가 BOM 붙은 utf-8을 거부한다 |
| 3 | 로그의 한글이 깨졌다 | 스크립트 머리에 "ASCII-only on purpose"라 적혀 있는데 지출 로그 문구가 한글이었다. **유료 레그의 유일한 감사 흔적이 처음 도는 날 읽을 수 없었다** |
| 4 | 🔴 하루가 done으로 닫혔다 | 완주 판정이 **수집 레그만** 봤다. 파생(머지·시리즈·리포트) 실패는 어디에도 등록되지 않았다 |

고친 방향:

- 원장 → `data/live/state/social_attempts_<date>.json`. **옛 자리도 계속 읽는다** — 못 읽으면 그날 지출이 0으로 리셋되고 재시도가 이미 산 태그를 다시 산다. 자리를 옮기는 변경에서 가장 비싼 실수가 그것이다.
- 쓰기는 `WriteAllText` + `UTF8Encoding($false)`, 읽기는 `ReadAllText`로 BOM 무관.
- Log 문자열은 ASCII로. 머리 주석에 **"Log 문자열에서는 위험이 아니라 확정"**이라고 정확히 적었다.
- 파생 실패도 하루를 연다(`Set-Derive` → `deriveFails` → 완주 판정). 파생은 공짜·멱등이라 다시 도는 값이 싸고, 닫아 두는 쪽의 값이 "오늘 수집이 조용히 증발"이었다.

**검증은 사고를 그대로 재현해서 했다.** 스냅샷 디렉터리에 BOM 파일을 심고 실제 호출 형태로 실행 → `day left INCOMPLETE on purpose ... pending: derive:social-merge` · `done=false` 확인 → 제거 후 정상 완주. 재실행 4회 **지출 0**(12태그 전부 파일이 있어 구조적으로 건너뛴다) · 원장 $3 유지. 원장 왕복은 별도 4검사(레거시 BOM 이어받기 · 새 파일 BOM 없음 · 새 자리 우선 · 파이썬 읽기).

**복구로 수치가 움직였다** — 소셜 창이 `2026-03-10..07-30` → `2026-01-21..07-31`로 늘었다(태그 수집이 과거 게시물을 함께 가져온다).

| | 전 | 후 |
|---|---|---|
| 두 신호가 다 있는 팀 | 127 | **131** |
| 추적 아티스트 | 415 | **435** |
| 차트 밖에서 도는 팀 | 288 | **304** |
| izna 선행 | 58일 | **160일** |

> **배운 것**: 돈이 걸린 코드의 검증은 계산이 맞는지만 묻지 않는다. **산출물이 놓이는 자리·인코딩·실패했을 때 누가 알아채는지**까지가 검증이다. 셋 다 계산과 무관했고 셋 다 정적 게이트 밖이었다.

## 5. 수집 이전 실측 (결정 3의 입력)

핸드오프가 "유료 키·모델 캐시·멜론 MCP 레그를 실측하라"고 적어 둔 것에 답했다. **셋 다 이전을 막지 않는다.**

| 걱정 | 실측 |
|---|---|
| 유료 키 | 비밀값 **둘뿐** — `APIFY_TOKEN`(유료 $3/일) · `YOUTUBE_API_KEY`(무료) |
| 모델 캐시 | **28.6MB** ONNX · 런타임 페치 · 멱등. **torch·demucs는 daily 경로에 없다**(`--stems`일 때만) |
| 멜론 MCP | `daily_collect.ps1`에 **없다**. 옮기든 말든 상태가 같다 |

실제로 걸리는 것은 셋 다 아니다: ① 러너는 매번 새 디스크인데 `data/live/`가 **67.9MB**이고 하루 **5MB**씩 늘며 그 안에 **돈 원장**이 있다 ② **데이터센터 IP에서 소스가 열리는지는 여기서 잴 수 없다** ③ 예약 크론은 밀리고 건너뛰는데 **거른 날은 영구 결손**이다. 한 번 완주 **17~25분**.

**백업은 이 결정을 기다릴 이유가 없다** — 되돌릴 수 없는 관측 원본만 압축하면 **15.3MB · 하루 1.2MB**다.

세 층 구조로 정리했다: **1층 관측 원본**(불변·추가만·재취득 불가 → 버킷) · **2층 파생 정형**(언제든 1층에서 재생성 → 지금은 파일, 읽는 쪽이 생기면 Postgres) · **3층 제품**(`report.json` → 정적 대시보드 → git). 불변식 하나 — **2층은 백업하지 않는다. 재생성이 안 되면 그건 2층이 아니라 1층이다.**

🔺 **Postgres가 1층을 대체할 수 없는 이유**(도메인 소유자 질문): 차트는 "오늘"만 서빙해 **재취득이 불가능**하다. 파서가 틀렸거나 나중에 안 쓰던 컬럼이 필요해지면 원본 없는 날짜는 영구 손실이다. 용량도 근거가 안 된다 — 하루 2.8만 행(141파일 × 201행)이라 인덱스 포함 연 1.5~2GB인데 압축 원본은 연 440MB다. 그리고 스토어를 DB로 바꾸면 **모듈 CLI가 네트워크·자격증명 없이는 못 돈다**(지금은 전부 오프라인·결정적이고 스모크가 그 위에 선다).

## 6. Supabase MCP·스킬 등재 · 멜론 복귀

- `.mcp.json`에 `supabase`(HTTP · `read_only=true` · `features=database,docs,storage`). **PAT 불필요**(동적 클라이언트 등록 + OAuth). 헬스체크 `401` = 서버 정상.
- 스킬 2종(`supabase` · `supabase-postgres-best-practices`)을 `npx skills add supabase/agent-skills`로 `.agents/skills/`에 벤더링. MIT · 상위 LICENSE 동봉 · `skills-lock.json`이 해시 고정 · 내용 훑음(전부 마크다운, 실행·전송 지시 없음).
- 🔴 **`.claude/skills/` 아래 심링크는 gitignore.** 이 저장소는 `core.symlinks=false`이고 기존 심링크가 0개라, 커밋하면 Windows 체크아웃에서 경로 문자열이 든 일반 파일로 풀려 **스킬이 조용히 사라진다.** 실물 41파일만 커밋한다.
- ⏳ OAuth는 대화형 세션에서 `/mcp` → supabase → Authenticate. **이 세션에서는 supabase 도구가 안 잡혔다.**
- 🟢 **딸린 소득: 멜론 MCP가 붙었다.** 도구 18종이 올라왔다(대기 목록 4번 · 4번째 렌즈 복귀 조건). 이번 세션에서 열지는 않았다 — 렌즈를 늘리면 차트 커버리지·좌측 절단·시장 수가 전부 움직여 그 자체로 한 세션짜리다.

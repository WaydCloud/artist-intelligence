# CATALOG — 분석 축 후보 목록 (sonic-profile)

> 2026-07-29 전수 조사. **무엇을 더 잴 수 있는가**의 지도.
> 채택 규율은 [`../modules/sonic-profile/RULES.md`](../modules/sonic-profile/RULES.md) §3(3층 구조)·§3.1.7(채택 조건), 결정은 [`DECISIONS.md`](DECISIONS.md) D-031.
>
> **이 문서는 쇼핑 목록이지 계획이 아니다.** 여기 있다는 것은 "잴 수 있다"이지 "재야 한다"가 아니다.
> 각 축은 채택 전에 원장(정의·도메인 근거·하중·테스트·한계)을 통과해야 하고, **판별력은 코호트에서 실측해야 안다** — D-031에서 `danceability`가 천장에 붙고 `muse`가 퇴화한 것이 그 실례다.

## 0. 비용 계층 (이게 우선순위를 정한다)

| 계층 | 무엇 | 추가 비용 | 소급 적용 |
|---|---|---|---|
| **T0** 순수 DSP | 모델 없음, librosa/numpy | **0** (새 의존성·새 모델 0) | 저장된 벡터에서 나오면 **가능** |
| **T1** effnet 편승 | 이미 계산하는 1280d 임베딩에 헤드만 추가 | 헤드당 0.5~2.8MB + 추론 1회 | 불가(오디오 필요) |
| **T2** musicnn 편승 | 이미 계산하는 200d 임베딩에 헤드만 | 헤드당 <0.1MB | 불가 |
| **T3** 같은 mel · 새 임베딩 | 우리 mel 그대로, 임베딩 모델만 추가 | 16~348MB + 추론 1회 | 불가 |
| **T4** 새 mel 사슬 | 전처리부터 다름 — **§3.3 지뢰를 새로 밟는다** | 모델 + 전처리 검증 | 불가 |
| **T5** 비-Essentia | 별도 라이브러리 | 의존성 승인 필요 | 불가 |

> **T4의 위험을 과소평가하지 말 것.** RULES §3.3 실측에서 mel `type`을 하나 잘못 두자 전 곡이 `Electronic---Techno`로 뭉갰다. 새 전처리는 **예외가 아니라 그럴듯한 오답**을 낸다.

## ⚠ 채택하지 말 것 / 조심할 것

- **`gender`(여성/남성 음성 분류, #49)** — 기술적으로 가능하나 **채택을 권고하지 않는다.** 아티스트를 성별로 분류하는 파생 지표는 `AGENTS.md` §5("지표를 아티스트 개인의 평가에 쓰지 않는다")와 `DOMAIN.md` §7 윤리 민감점에 정면으로 걸린다. 보컬 편성을 알고 싶으면 `voice_instrumental`(#42)과 악기 태그로 충분하다. **필요가 실증되기 전에는 열지 않는다.**
- **`approachability`·`engagement`(#50~55)** — "대중성"·"몰입도"는 **가장 평결로 붕괴하기 쉬운 이름**이다(DOMAIN §0). C층 구성물 지표로만, "누구의 정의인가"를 밝히고, **단독 근거 금지**로 실어야 한다. 이름을 그대로 UI에 쓰면 "AI가 히트를 예측한다"로 읽힌다 — `AGENTS.md` §5 금지.
- **임베딩 유사도(#72~80)** — "제2의 아이유" 같은 표현은 §5 위반. 산출은 **이웃 목록과 거리**까지다.
- **`spectral_rolloff`류 고역 축** — `sr=22050`이라 나이퀴스트 11kHz. 원리적 한계를 병기하지 않으면 잘못 읽힌다.
- **여러 태그셋의 확률을 합산·평균하지 말 것** — MTT·MTG-Jamendo·Discogs는 주석 프로토콜이 다르다. 교차확인은 **일치/불일치**로 읽지 산술로 섞지 않는다.

## 권고 순서

1. **T0-a 소급 9종** — 비용 0, 즉시. `organic_ratio`는 이미 실측까지 끝났다.
2. **T0-b DSP 28종** — 새 의존성 0, 콜드 실행 편승. 스테레오·라우드니스 축은 이미 깔린 배관 재사용.
3. **T1 effnet 헤드** — 편승이라 싸다. `mood_acoustic`/`mood_electronic`/`voice_instrumental`/`timbre`부터.
4. **T3 아티스트·레이블 임베딩** — 가장 새로운 축. 18.6MB×2로 시작.
5. **T5 Demucs** — 승인 대기 중.
6. **T4·MAEST** — 비용을 먼저 재고 결정.

> **전부 하지 말 것.** 축이 늘면 리포트가 읽히지 않고, 판별력 없는 축(D-031의 `danceability`·`grid_deviation_ms`)이 섞이면 신뢰가 깎인다. **코호트에서 분산이 나오는지 먼저 재고, 안 나오면 안 싣는다.**

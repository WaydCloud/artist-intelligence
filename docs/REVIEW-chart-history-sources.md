## 권고 수집 설계

**A. 케이스 궤적 재구성**: Hot 100 = GitHub 데이터셋 `date/*.json`(스크랩 불필요) + Wikipedia 교차 + 불일치 시 acharts 3자 대조 · UK = Official Charts 케이스별 소량 열람 · 스트리밍 보조 = Kworb 트랙 페이지(곡당 1페이지) + Apple 아카이브(2017-08~).

**B. 동시대 코호트 소급**: US = GitHub `date/2021-10-02.json` 즉시 가능 · UK = Official Charts 해당 주 즉시 가능 · Spotify = 공식 CSV(2017~) · **국내 = Wayback 멜론/가온 스냅샷 보조**(전 주간 완전 커버 필요 시 D-005 정식 경로(음콘협 제휴)로 승격) · 2013~16 Spotify 코호트는 **원리적 완전 재구성 불가**(iTunes WW로 부분 근사만).

## 한계·불확실성

- GitHub 데이터셋 라이선스 불명(LICENSE 404 실측 → API `license: null` 재확인) — 순위·사실 필드만 내부 파생 저장·원문 재배포 금지 전제의 판정. **D-035 ②로 승인됨**(D-020 "빌보드 배제"는 직접 스크랩 기준이며 이 경로는 빌보드 서버에 접근하지 않는다). 정확도는 스모크로 검증됐고 **라이선스 불명은 해소되지 않았다** — 저장 전제는 계속 구속한다.
- acharts 정확도 표본 1주 → **3주 300칸으로 확대 실측**: 사실 불일치 1건이 나왔고 **acharts 측 오류**로 판정됐다(엔티티 연결). **acharts 단독 근거 사용 금지** — 3자 대조의 2선으로만 쓴다.
- Official Charts 약관 원문 미확인(robots.txt 앞부분에 차트 경로 차단 없음만 확인) — "소량 열람" 설계는 보수적 전제.
- Kworb 주간 2013-09 소급·Official Charts 1952 소급은 검색 기반 추정. Wayback 커버리지는 주별 불균일.
- **스모크 표본은 2013~2023에 한정된다** — 1958~2012 구간(예: 시티팝 원형 시대)으로 소급하면 그 시대 표본으로 다시 돌려야 한다.

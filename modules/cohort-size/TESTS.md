# cohort-size · TESTS (수용 조건)

> smoke는 네트워크 0, 커밋 픽스처만. `PYTHONPATH=modules/cohort-size/src python -m cohort_size selftest` (jsonschema 필요, 없으면 실패).

## §1. 통계 (stats.py)

1. 카이제곱 생존함수 알려진 값: df 1 · 2 · 3 · 4에서 95% 임계값 → 0.05, χ²=20 · df 10 → 0.029252688
2. 윌슨: 5/10 → 0.2366 ~ 0.7634, 0/10 → 0 ~ 0.2775
3. 크라메르 V: 완전 분리 표 1.0, 같은 비율 표 0.0
4. 몬테카를로 정확검정이 2 × 2 피셔 정확검정(초기하 전수)의 4 표준오차 안
5. 코크란-아미티지 z² = 2행 표의 피어슨 χ²
6. 홀름 알려진 예: (0.01, 0.04, 0.03) → (0.03, 0.06, 0.06)
7. 검정 불가 표는 사유를 들고 나온다(성공 0 · 구간 하나)
8. 같은 시드 → 같은 몬테카를로 p

## §2. 데뷔 인원 규칙 (sizes.py)

9. 첫머리 문장이 멤버 목록보다 우선 · 10. "Originally as N" · 11. 전 멤버 없음 → 현재 인원 · 12. 현재 + 전 멤버 → 미판정, 범위 보존 · 13. 유닛 범주 · 소문자 인포박스 · 남성 범주 거부
14. **회귀**: 커밋 픽스처의 2022 ~ 2024 행이 기획 저장소 `sizes.csv`의 162행(`tests/fixtures/sizes_2022_2024.csv`)과 순서까지 같다

## §3. 이름 대조 (match.py)

15. 오탐 없음: Bubble · Pretty · Rush · Stars · Curious · CocaNButter · January · GI · APRIL(날짜) · NewJeans(템플릿 인자 줄)
16. 정탐: NewJeans · ILLIT · MEOVV(셀 속성 줄) · KISS OF LIFE(닫히지 않은 셀 속성) · CSR · KATSEYE · APRIL(그룹 링크)
17. 리다이렉트 본문은 그 해 절만 읽는다("Achievements by artists" 안 읽음, 없는 해는 빈 값)
18. 표 줄이 0인 해는 목록 줄을 읽고 곡명은 지운다
19. 멜론 순위 · 아티스트 파싱, 경계 대조, 링크만 인정 이름("one")은 멜론에서 세지 않음
20. 써클 괄호 조각 정확 일치, 한글 공백 제거 비교
21. Spotify 정확 일치, 동명 충돌 목록 제외

## §4. 분석 (analyze.py)

23. Spotify는 종합에 들어가지 않고 검정이 없다
24. 창 미완 코호트는 기본으로 검정 제외 · 25. `--include-incomplete`면 포함

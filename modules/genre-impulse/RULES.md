# genre-impulse · RULES (기준 원장)

> 미시 판단의 기준은 임의가 아니다 — `정의 · 도메인 근거 · 하중여부 · 테스트 · 한계` ([`../../AGENTS.md`](../../AGENTS.md) §2.1).
> 임계값은 도메인 소유자(A&R) 소유이며 CLI로 노출한다. 코드에 은닉 금지.

## §1. 불변식

- **무단정**: 출력 어디에도 "뜬다/차트인한다/도입하라" 단정을 넣지 않는다. 형식은 항상 *"임펄스 X의 검출 규칙에 매치 — 참고: 과거 사례 리드타임·모드·한계"*.
- **커버리지 정직**: 검출 규칙이 없는 임펄스는 숨기지 않고 사유와 함께 표면화한다(축 공백·스템 잠금·미실측). 규칙 n/원장 전체를 KPI로 상시 노출.
- **원장 인용 규율**: 임펄스 레코드 인용 시 확실성 6등급(D-033 보완⑥)을 병기하고, **중간 미만 등급의 사실은 리포트 표면에 올리지 않는다**(원장에는 남는다).
- **결정성**: 같은 입력 → 같은 산출(`generatedAt` 제외). 백분위는 당일 코호트 내 순위로 계산(외부 상태 없음).

## §2. 검출 규칙 원장

검출 규칙 = 임펄스의 사운드 서명을 sonic-profile 축의 **코호트 내 백분위 조합**으로 표현한 것. 규칙은 **사전 등록 → 정답지 실측 검증 → 원장 등재**의 순서로만 추가된다(결과 보고 규칙을 만들지 않는다).

### §2.1 `hyperpop-texture`

- **정의**: 당일 차트 코호트에서 `organic_ratio` 백분위 ≤ **P_low** 이고, (`spectral_flatness` ≥ **P_high** 또는 `over_unity_ratio` ≥ **P_high**)인 트랙.
- **도메인 근거**: A2.1 실측(2026-07-30, CASEBOOK §A2.1) — 정답지 Savage(organic P2.2·flatness P87.9·over_unity P80.2)·Whiplash(organic P17.6·over_unity P100·attack P96.7)가 이 조합에서 코호트 극단에 위치. '쇠맛' 계보에서 가장 일관된 축은 organic_ratio↓(5곡 중 3곡 하위 20%). 사전 등록 축 중 brightness는 판별력 없음이 실측돼 **규칙에서 제외**했다.
- **하중여부**: **하중받는 기준** — 매치 여부가 A&R의 후속 검토(요소 차용 후보 청취)를 바꾼다.
- **임계값** (관습값, 도메인 소유자 재조정):
  | 이름 | 화면 표기 | 기본값 | CLI |
  |---|---|---|---|
  | P_low (하위 백분위) | 하한으로 볼 백분위 | 20 | `--low-pct` |
  | P_high (상위 백분위) | 상한으로 볼 백분위 | 80 | `--high-pct` |

  > `P_low`·`P_high`는 **이 문서 안의 기호**다. 화면 라벨은 모듈이 `knobs[].label`로 싣고(위 표기), 대시보드는 그것을 그대로 쓴다 — 기호가 슬라이더 라벨로 나가면 문서에서만 통하는 표기가 클라이언트 화면에 새는 것이다(DESIGN §6.1). 표기를 바꿀 때는 여기와 `cli.py`를 함께 고친다.
- **테스트**: TESTS §3 (정답지 트랙을 코호트에 섞으면 매치, 임계를 극단으로 올리면 매치 0).
- **한계**: ① 비교 모집단이 당일 코호트라 **코호트 구성에 상대적** — 코호트 전체가 하이퍼팝화되면 규칙이 둔감해진다(분포 중앙값 추이를 함께 보라) ② 30초 프리뷰 발췌 ③ 정답지 표본 5곡(계보)·검증 1케이스 — 새 사례가 반증하면 규칙 버전을 올린다 ④ 보컬 처리 축 부재로 하이퍼팝 시그니처의 절반(피치 시프트 보컬)은 못 본다 — 축을 정의·구현하고 게이트를 돌렸으나(2026-07-30) **둘 다 채택 보류**다. 보류 사유는 둘로 갈린다 — `vocal_pitch_shift_proxy`는 **판별력 없음**(정답지가 예측과 반대로 코호트 중앙 이하), `vocal_tuning_hardness`는 **측정 결함**(pyin 해상도 10센트에 값이 양자화 — 고유값 6/96, 이후 철회). 상세는 sonic-profile RULES §3.8.4.1. **대체 축도 실패했다**(D-038 · 2026-07-30 게이트): `vocal_note_f0_spread`(지속 노트 안 f0 분산)는 **측정 결함을 고쳤으나**(고유값 92/96 · 격자 오프셋 불변 · 해상도 독립 2.37%) aespa 3곡이 P69.8·59.4·47.9로 **판별력이 없다**. 즉 이번에 틀린 것은 측정이 아니라 **주장**이다 — 쇠맛 계보의 서명은 지속 노트의 f0 안정성에 없다. **이 한계(피치 시프트 보컬 미관측)는 그대로 유효하다.**

## §3. 데이터 계약

- **임펄스 원장**: `data/research/genre-impulse/impulse.schema.json` 준수 레코드만 로드. 위반 레코드는 스킵하고 insights에 보고(조용한 무시 금지).
- **sonic 스냅샷**: sonic-profile `fetch` 산출(`records[].features`). `organic_ratio`는 스냅샷에 없고 저장 라벨에서 재계산된다(derived) — 재구현하지 않고 sonic-profile의 `derived.derive_all`을 **import해 재사용**한다(AGENTS §1 중복 방지). ⚠ 이는 D-007(모듈 간 코드 import 금지, 데이터 계약만)의 **문서화된 한시 예외**다: 공유 프리미티브는 "먼저 만든 쪽이 packages/에 두고 다른 쪽이 참조"가 정본 경로(sonic-profile SPEC §5.1)이며, 파생 계산의 `packages/` 승격은 구조 변경이라 별도 승인 후 이 예외를 해소한다. 실행 시 `PYTHONPATH`에 두 모듈 src가 필요함을 CLI 도움말에 명시.
- **report.json**: 공유 report-schema 무변경 준수.

## §4. 차트 데이터 규약

- 매치는 **축별 백분위 격자**(heatmap `match-axes`)로 낸다: 행 = `"아티스트 - 곡명"`(워치리스트는 `★` 접두), 열 = 규칙 축의 **화면 표기**(`AXIS_LABELS` — 저장 키를 그대로 찍지 않는다), 칸 = 코호트 백분위.
  - **막대를 쓰지 않는 이유**: 예전에는 하한 축(organic_ratio) 하나만 막대 길이로 그렸는데 그 축은 "낮을수록 규칙 부합"이라 **긴 막대가 덜 부합**을 뜻했다 — 길이의 방향과 주장의 방향이 반대였다. 세 축이 전부 같은 단위(코호트 백분위)라 하나의 눈금에 나란히 놓을 수 있고, 규칙의 모양(첫 열이 옅고 나머지 중 하나가 진함)이 격자에서 그대로 보인다.
  - **격자에 `scale: "value"`를 반드시 싣는다.** 격자 프리미티브의 기본은 순위(작을수록 강함)라, 백분위를 그냥 실으면 낮은 값이 가장 진하게 칠해지고 범례가 그것을 "상위"라고 부른다(2026-07-30 육안 검사에서 실제로 그 상태였다). 범례 문구(`strongLabel`·`weakLabel`·`emptyLabel`)도 리포트가 정한다.
  - ⚠ bar를 낼 때 **키는 `name`이다**(`label`이 아니다). 공유 계약(대시보드 `BarChart`·타 모듈 전부)이 `name`이며, `report-schema`는 `data`를 제약하지 않으므로(`"data": {}`) 틀려도 검증을 통과한다. 2026-07-30까지 이 모듈만 `label`을 내보내 **막대 11개가 이름 없이 그려졌다** — 스키마가 못 잡는 계약은 육안 확인에서만 드러난다(AGENTS §7).
- 규칙 미확정 임펄스는 **`notAnswered`**(R7)로 낸다 — 인사이트 목록의 꼬리가 아니라 화면 위쪽의 "답하지 않는 것"이 그 자리다.
- 곡별 백분위를 **insights에 다시 찍지 않는다**. 격자가 이미 보여주고, 텍스트로 옮기면 저장 키(`organic_ratio` 등)가 화면에 새어 나온다. 인사이트에는 규칙 귀속(규칙 id · 매치 수)만 남긴다.
- tunable 뷰: `view=impulse-rules`, 슬라이더 2개(P_low·P_high) — 재계산은 저장된 백분위에서 파생(오디오 재접근 없음).
  - payload는 **곡별 백분위(`tracks`)와 규칙의 형식(`rules`)을 함께 싣는다.** 분포(`pools`)만 보내면 컷 선은 움직여도 매치 목록이 얼어붙는다 — 임계를 낮췄을 때 새 곡이 나타날 수 없기 때문이다.
  - 규칙 형식은 세 조합이다: `lowAll`(전건 하위) · `highAll`(전건 상위 — §2.1.2) · `highAny`(하나 이상 상위). **대시보드 튜너가 같은 세 조합을 구현해야 한다** — 한쪽만 알면 CLI와 화면의 매치가 갈라진다.
  - 대시보드에 이 뷰의 핸들러가 없으면 **모른다고 표시**한다. 예전에는 미지의 view가 `Whitespace`로 흘러 `matrix.cols`에서 죽었고, 그 결과 **대시보드 전체가 언마운트**돼 다른 모듈 탭까지 못 보게 됐다(2026-07-30 실측).
